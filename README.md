# NSJV Skills Transition Dashboard

Interactive dashboard of feeder occupations into four North San Joaquin Valley target trades
(Electricians, Operating Engineers, Industrial Machinery Mechanics, HVAC & Refrigeration).
Pick a target and a feeder to see transferable strengths, the training gap, and barriers to entry,
plus a bubble-pack cluster of all feeders by skill gap.

Data: O*NET 30.3 (knowledge, essential + transferable skills); entry requirements from BLS OOH & O*NET.
